# Threat model (draft, authored 2026-11-13)

**Nothing in this repository is audited.** This document is a working analysis by the infra/security-docs workstream, based on reading
`contracts/src/*.sol` and the existing docs. It is not an audit, was not reviewed by an external party, and will be incomplete. "Implemented"
means code exists and some test touches it; it does not mean the property is proven.

Guarantee labels: **[C]** cryptographic (enforced by signature/EVM rules), **[G]** governance (holds only while privileged keys behave),
**[E]** economic (holds only while incentives/markets behave), **[O]** operational (holds only if off-chain processes run).

Roles in the code: `DEFAULT_ADMIN_ROLE` (createMarket, setMarketState any, setFees, setOracle, rebalanceBackstop, registerModule/lockModules,
setAdlMaxPremBps, unpause), `GUARDIAN_ROLE` (pause globally, restrict market state; cannot return to Normal/Recovery), `BACKSTOP_ROLE` (trades backstop inventory
via `backstopPlace`). **No timelock contract exists in this repo**; admin actions are immediate.

## Stress campaign (2026-11-13)
A model-based fuzz suite and Foundry invariants were written to stress liquidation, bad debt, insurance, the backstop and ADL under oracle shocks from -60% to +150% (`test/stress.test.js`, `foundry-test/Stress*.sol`). They found 2 critical, 4 high and several lower issues, 8 of which were fixed (see docs/GAPS.md for the table). **Fixed afterwards (phase 1, docs/BACKSTOP_DESIGN.md): BACKSTOP-1 accounting, ADL-2, cross-market debt clearing. Phase 2 (soft threshold, auction, forced unwind) added 2026-11-14. Still open: hard bound on backstop inventory (the cap is soft), taker griefing/wash within the band (bounded by `maxDiscBps <= bandBps`, untested against real flow), elevation-clock reset by moving inventory to the threshold, the withdrawal-run window while debt is uncleared, ADL candidate completeness, ADL rounding leak.** This is test evidence about this code, not an audit.

## Explicit non-claims
- No formal verification, no external audit, no economic simulation of liquidation cascades, no adversarial testnet. Property tests exist (`test/fuzz.test.js`)
  and the numbers quoted in docs/BENCHMARKS.md for failing tests are historical; the current counts are in the final report of the 2026-11-13 stress work and in docs/GAPS.md.
- Mainnet-style guarantees about "trustless" matching apply only to on-chain state transitions; sequencer and oracle remain trusted.

Phase 2 additions: `takeBackstop` is permissionless and reentrancy-guarded, performs no token transfer or external call, and prices at INDEX +/- a governed discount (<= 300 bps and <= bandBps), so a taker's edge is bounded by the discount minus the fee. The takers' margin check applies when exposure grows. Guardian can only tighten (`setBackstopCfg`, `setBackstopTakeFee`) or close `backstopPlace`; only admin loosens. A malicious or mistaken admin can set the threshold very low (forcing frequent unwinds of profitable winners at mark) or the unwind age very short: treat `setBackstopCfg` as a user-facing risk parameter behind the timelock.
